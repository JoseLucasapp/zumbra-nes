# CPU Ricoh 2A03 / NMOS 6502

## Escopo

A Z20 implementa os 151 opcodes oficiais do conjunto NMOS 6502 usados pelo núcleo Ricoh 2A03 do NES. Opcodes não oficiais não fazem parte do contrato `0.2.0` e geram um `panic` controlado.

## Registradores

| Campo | Largura lógica | Função |
|---|---:|---|
| `A` | 8 bits | acumulador |
| `X` | 8 bits | índice X |
| `Y` | 8 bits | índice Y |
| `SP` | 8 bits | ponteiro da stack em `$0100-$01FF` |
| `PC` | 16 bits | program counter |
| `status` | 8 bits | flags do processador |

O código usa `int` para o estado e aplica wrapping explícito com `band 0xFF` e `band 0xFFFF`. Isso mantém o comportamento de 8/16 bits e evita conversões implícitas entre métodos na versão atual da linguagem.

## Flags

```text
NV-BDIZC
```

- `C`: carry/borrow;
- `Z`: zero;
- `I`: interrupt disable;
- `D`: decimal armazenado, sem efeito decimal em ADC/SBC no 2A03;
- `B`: marcador de software em valores empilhados;
- `U`: bit não usado, mantido em 1;
- `V`: overflow assinado;
- `N`: bit negativo.

## Modos de endereçamento

- implied;
- accumulator;
- immediate;
- zero page;
- zero page X;
- zero page Y;
- absolute;
- absolute X;
- absolute Y;
- indirect;
- indexed indirect `(d,X)`;
- indirect indexed `(d),Y`;
- relative.

A indireção de zero page faz wrap em `$FF → $00`. `JMP ($xxFF)` reproduz o wrap de página do hardware NMOS.

## Categorias de instruções

### Carga e armazenamento

`LDA`, `LDX`, `LDY`, `STA`, `STX`, `STY`.

### Aritmética e comparação

`ADC`, `SBC`, `CMP`, `CPX`, `CPY`, `INC`, `DEC`, `INX`, `INY`, `DEX`, `DEY`.

### Lógica e bits

`AND`, `ORA`, `EOR`, `BIT`, `ASL`, `LSR`, `ROL`, `ROR`.

### Transferência e stack

`TAX`, `TAY`, `TXA`, `TYA`, `TSX`, `TXS`, `PHA`, `PHP`, `PLA`, `PLP`.

### Controle

`JMP`, `JSR`, `RTS`, `BRK`, `RTI`, `NOP` e oito branches condicionais.

### Flags

`CLC`, `CLD`, `CLI`, `CLV`, `SEC`, `SED`, `SEI`.

## Ciclos

A tabela `opcodeInfo` expõe mnemonic, modo, bytes, ciclos-base e indicação de possível page crossing.

A CPU adiciona penalidades somente onde o hardware oficial adiciona:

- leituras absolute X/Y e indirect Y;
- branches tomados;
- branches tomados que cruzam página.

Stores e read-modify-write indexados têm ciclos fixos.

## Interrupções

- NMI é edge-latched via `requestNmi` e tem prioridade;
- IRQ é level-sensitive via `requestIrq`/`clearIrq`;
- IRQ respeita a flag `I`;
- BRK usa o mesmo vetor de IRQ, com `B = 1` no status empilhado;
- RTI restaura status e PC.

## APIs principais

```zumbra
var cpu << cpu6502.create(systemBus);
var cycles << cpu.step(systemBus);
cpu.requestNmi();
cpu.requestIrq();
cpu.clearIrq();
```

Metadados:

```zumbra
var info << cpu6502.opcodeInfo(0xA9);
var official << cpu6502.isOfficialOpcode(0xA9);
var count << cpu6502.officialOpcodeCount();
```

## Limitações deliberadas

- sem opcodes não oficiais;
- sem precisão bus-cycle por micro-operação;
- sem OAM DMA;
- sem NMI produzida por PPU real;
- sem IRQ produzida por APU/mapper;
- sem validação por ROM comercial.

Esses pontos não impedem a CPU de nível de instrução da Z20 e serão integrados conforme PPU, APU e mappers forem adicionados.
