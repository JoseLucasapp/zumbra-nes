# Debugger Z23

## Recursos

- attach em uma máquina viva;
- pause/resume;
- step instruction;
- step frame;
- breakpoint de PC;
- breakpoints de leitura/escrita;
- registradores e flags;
- memória e stack;
- disassembly;
- snapshot do mapper;
- trace limitado;
- motivo da pausa.

## Frontend

- `F`: abre o painel de diagnóstico;
- `C`: executa uma instrução e atualiza o painel.

A API do debugger também pode ser usada por ferramentas futuras para configurar breakpoints e executar até um limite de instruções.
